# Third-party services

This variant uses official DeepSeek model and Search APIs via fetch. No third-party SDK, remote JavaScript, website session bridge or vendor WASM module is distributed in this package.

DeepSeek API use is subject to DeepSeek's terms, billing and policies. The user's own key is required. Original search sources remain the property of their respective publishers.

The extension's source is covered by the bundled LICENSE.

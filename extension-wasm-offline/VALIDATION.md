# Official API edition validation

2026-11-02 · extension-wasm-offline v0.2.1

- 20 Node API/background tests pass: model/search calls, evidence mapping, bounded queries, API errors, SSE framing/Unicode, cancellation, sender boundaries and prompt redaction; session-only key writes, legacy local-key deletion on every worker initialization, worker/session lifetime, blank-input revalidation, failed replacement, secret-free notifications and fail-closed storage setup.
- The original issue was reproduced before the fix: configuration wrote the raw synthetic key to local storage, and an old persistent key was treated as configured. Both regression checks now pass with no credential in persistent extension storage.
- A temporary real MV3 Chromium installation verifies Welcome, current-session revalidation, explanations, searched expansion, cached short, News, retry/cancellation, native editor Cut, A/B/C layouts and context off. Content-script probes cannot read local/session keys or observe secret storage-change values.
- The browser test removes the session key and confirms missing-key recovery without a lookup. It also seeds a synthetic legacy disk key, closes Chromium and restarts the same profile: the old local key is deleted, the previous session key is absent, saved consent/preferences remain and setup requires a fresh entry.
- All network replies and keys are synthetic; no personal account, credential or paid lookup is used. Existing API test commands remain valid. Evidence generated by the security-fix workflow is kept in managed temporary/artifact storage rather than in this package.

Commands: `node --test tests/wasm-offline-api.test.cjs`, `node tests/wasm-offline-browser.cjs`, `python3 tools/package-wasm-offline.py`.

Session storage is not a defense against a compromised device or live memory inspection. Removing an old local entry does not establish forensic erasure from old profiles or backups. Live API account/billing acceptance, Chrome 114, long sleep/resume and Chrome Web Store approval are not established by controlled tests.

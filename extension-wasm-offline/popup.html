Reading layout & API details

Select reading text and click the small icon, or press Ctrl+X (⌘X on Mac). Copying alone never starts a lookup. Cut stays unchanged in input fields and editors.

Your DeepSeek key stays only in memory for this browser session; preferences are saved on this device. Re-enter your key through API settings after restarting Chrome or reloading/updating the extension. No DeepSeek website tab or website login is needed.

Explanations and News need an internet connection and a valid DeepSeek API key. Explanations are AI generated; check news dates and original sources.

Normal webpages are supported. Browser pages, the Chrome Web Store, PDFs, input fields and document editors are outside this version’s scope.

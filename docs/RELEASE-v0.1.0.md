# Explained 0.1.0 — experimental preview

A small reading companion for Chrome: highlight a phrase for a contextual explanation, or ask for recent news beside your reading.

This release includes Explain streaming and expansion, on-demand News, three card layouts, English/Simplified Chinese/Traditional Chinese, context visibility and control, global/site pause, and coordinated request cancellation.

Install by extracting the extension ZIP, opening `chrome://extensions`, enabling Developer mode and loading the `explained-extension` folder. Open the toolbar panel to enable lookups, sign in to DeepSeek, leave its dedicated tab open, and refresh reading pages. No official paid API key or build step is required.

**Preview limits:** an undocumented website integration and a remote official solver asset; independent authenticated-account checks and current News citation mapping remain pending. Public distribution needs separate website-terms and Chrome-policy review. This is not a claim of store eligibility. See the repository’s privacy and validation documents.

The controlled suite contains 14 contract/bridge tests and 23 UI checks. These do not prove live account behavior, source accuracy or latency. Documentation screenshots use synthetic answers.

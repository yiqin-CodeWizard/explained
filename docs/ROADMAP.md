# Roadmap

## Validate the preview

- Exercise the installed build with a real account and verify current News source metadata.
- Record reproducible cold/warm timings without private prompts, identifiers or authentication data.
- Verify login expiry and real browser tab discard/sleep recovery.
- Resolve website terms and remote-WASM execution/distribution questions before a broader launch.

## Improve reliability

- Add fixtures for confirmed website stream changes.
- Improve source/story mapping while keeping unverified states explicit.
- Test more page structures and document-editor exclusions.
- Review accessibility, long phrases, narrow windows and keyboard selection across sites.

## Consider later

An authorized provider integration, optional topics and verified Chromium-browser support can be evaluated separately. PDFs, document editors, Firefox/Safari support, a hosted service and Chrome Web Store publication are not promised for this preview.
